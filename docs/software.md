# 一间属于你的直播监控室

DD 监控室 CE 是面向 Windows 的开源直播监控室。在同一个窗口中播放多路直播、查看主播开播状态，并同时录制需要保留的直播画面，方便后续回看与制作切片。B 站直播原生支持，其他平台通过独立插件扩展。

它主要服务于多路直播的日常监控与录制。如果只是想看直播，也可以将它当作一个集中观看的地方，关注不同平台的主播时，不必反复切换网页，并且软件的占用相较于正常使用网页或者electron架构的软件会低不少。

## 导入直播间，开始监控

日常使用时，添加想要观看的主播直播间链接，再从关注列表将卡片拖进画面格子即可。其他平台的直播间需要先安装并启用对应平台插件。[查看添加与安装步骤](/guide)。

软件定期刷新关注主播的开播状态，支持开播提醒、置顶与排序。启用静音悬停预览后，可以先看看主播正在播什么，再决定是否放入画面墙。

将重点关注的一路放大，其他直播留在旁边观察；需要时再切换主画面或单格全屏。每一路都能独立调整音量、静音、暂停、重载与画质，按自己的习惯决定看谁、听谁。

## 一边观看，一边多路录制

想保留多位主播的直播内容，可以在多路同屏播放的同时，分别开启需要的直播间录制。不必等看完一路再录另一路，后续制作切片时也能从不同直播视角中挑选素材。

首次使用前，在「设置 → 录制」中确认保存目录与录制设置，再通过各格子的录制按钮开始或停止。软件提供 NVIDIA、Intel 与 AMD 硬件编码选项，按设备选择合适的方式。

多路播放与录制会共同占用网络、解码、编码和磁盘资源。建议先从少量直播间开始，确认播放与录制正常后，再增加路数或提高画质。

## 不同平台，放在一起观看

B 站直播由本体提供，也支持扫码登录与关注导入。虎牙、斗鱼、抖音通过国内直播平台插件接入，Twitch 与 YouTube 通过海外直播平台插件接入。

添加后，这些直播间都可以放进同一面画面墙。平台插件独立安装、独立启用，按自己的观看需求选择即可。账号权限、直播画质与网络访问仍以各平台的实际支持为准。[浏览平台插件](/plugins/)。

## 想听多位主播解说，再开启比赛二路

想同时观看多位主播对同一场比赛的解说，可以安装[比赛二路同步插件](/plugins/match_sync)，进入二路模式，将想一起看的主播卡片拖入观看区域，并选择一路比赛直播作为主画面。

开启自动对齐后，插件会尝试匹配比赛画面、调整直播之间的时间差。这样就能在使比赛画面同步的情况下，同时收听多位主播的解说；各路声音可分别控制，弹幕也可以合并阅读。

自动对齐需要各路有足够的共同比赛画面。遇到广告、切屏或画面差异较大时，可能暂时无法匹配，仍可手动微调偏移。

## 多画面与布局

- 最多同时管理 16 路直播画面，从关注列表拖入指定格子。
- 横屏提供平分、大带小和弹幕布局；竖屏提供顶部关注栏与纵向画面墙。
- 将窗口拖成另一个方向时，切换到可容纳相近路数的布局。
- 每个格子可以独立暂停、重载、调整音量、静音与画质，也可单格全屏观看。

切换深浅色或跟随系统，使用本地图片、静音循环视频作为背景。拖动预设布局的内部边框调整画面比例，再将主播位置、比例与声音设置存成直播间组合，方便下次恢复。

## 弹幕集中阅读

选择弹幕布局，独立弹幕区跟随主画面。调整字号、屏蔽词与保留条数，在多个直播间之间切换时保留自己的阅读习惯。

## 竖屏显示器也能用

竖屏时关注列表移到顶部。主画面与小画面纵向排列，不需要把横屏窗口挤在狭长的显示器里。

## 独立扩展更多平台

| 插件 | 支持平台 | 主要功能 |
| --- | --- | --- |
| [国内直播平台](/plugins/domestic_live) | 虎牙、斗鱼、抖音 | 格子播放、实际画质、静音预览、聊天弹幕 |
| [海外直播平台](/plugins/global_live) | Twitch、YouTube | 格子播放、自动画质、静音预览、聊天弹幕 |
| [比赛二路同步](/plugins/match_sync) | B 站及已接入的平台 | 比赛画面对齐、多路混音与合并弹幕 |
| [B站直播互动](/plugins/bili_live) | B 站 | 弹幕、表情与直播礼物互动，需配套软件 |

平台插件与比赛二路同步分别启用，版本独立维护。建议先安装最新公开版软件，再按插件说明安装。[查看插件列表](/plugins/)。
