# 从下载到第一面直播墙

## 启动软件

1. 从[下载页](/download)获取 Windows 安装器 `DDMonitorSetup.exe`。
2. 运行安装器，按提示选择安装位置并完成安装。
3. 使用安装器创建的快捷方式启动 `DD监控室CE.exe`。
4. 首次启动时添加 B 站直播间号或官方链接；需要导入 B 站关注时再扫码登录。
5. 从关注列表拖入画面格子，选择布局，调整各路音量。

源码启动方式、libmpv 运行库准备与完整依赖见[软件 README](https://github.com/Lanpropro/DD_Monitor_CE)。

## 安装插件

::: warning 先确认配套软件
建议先升级到最新正式版，再按[插件兼容性说明](/download#插件兼容性)确认所需的最低软件版本与使用要求。
:::

优先在软件内打开插件商店，按需安装、启用并按提示重启。也可手动下载：

1. 到[插件列表](/plugins/)下载需要的插件 ZIP，下载按钮会提供各插件对应版本的独立 ZIP。
2. 打开软件「设置 → 插件」，点击「装载插件…」选择 ZIP，也可将 ZIP 拖入插件页面。
3. 确认插件出现在列表中，勾选启用。
4. 点击「重启以应用」；旧版本按页面提示保存并重启。重启后再添加该平台直播间。

每个 ZIP 顶层只有与插件 ID 相同的文件夹。**不要导入 GitHub 的 Source code ZIP**，也不要将两个插件包合并。

手动安装时，将插件文件夹放入当前数据目录的 `plugins_user/<ID>`。安装版默认在当前用户 AppData，便携版和源码版默认在程序旁；迁移后以「数据与存储」显示的目录为准。

## 添加其他平台直播间

- 国内平台：使用官方完整直播间链接，或 `huya:房间号`、`douyu:房间号`、`douyin:房间号`。
- Twitch：使用 `https://www.twitch.tv/频道名` 或 `twitch:频道名`。
- YouTube：使用直播视频链接，或频道的 `/live` 链接。关注频道可跟随其下一场直播；视频链接固定到单场直播。
- 纯数字房间号仍按 B 站处理。具体平台能力见[插件目录](/plugins/)。

添加后将关注卡片拖入格子。聊天弹幕需要选择包含弹幕格的布局；弹幕会跟随主画面。

## 升级或禁用插件

优先使用软件内插件更新入口，更新后按提示重启。手动导入与替换请遵循该插件发布说明；不要将同 ID 的两个版本作为独立插件重复安装。

如果只是暂时不用，取消勾选并保存重启即可。平台插件禁用后，对应关注与格子转为暂存；重新启用后恢复，已被其他内容占用的格子会保留新内容。

0.8 的六个独立平台插件需要先升级至 0.8 热修复 1。安装后沿用原有关注、账号、房间 ID 和分组，按包内声明接管对应平台并迁移设置；未被接管的平台可继续由旧组合包提供。无需重新添加主播。

国内插件的旧 ID 是 `huya_watch`，现为 `domestic_live`。配套最新版软件会迁移旧启用选择和插件设置，保留原关注、位置与画质；不要把两者当作两个独立插件同时安装。

## 常见问题

### 插件导入成功，却不能播放？

先确认软件构建是否包含插件所需接口，再检查网络能否访问平台、直播是否正在进行，以及 FFmpeg 是否可用。便携版随包提供 FFmpeg；源码环境需按软件说明安装依赖，具体版本以对应软件与插件的依赖说明为准。

### 有画面，没有聊天？

选择弹幕布局，确认主画面是对应平台直播间。部分 YouTube 直播关闭聊天。各插件支持的聊天读取、发送与互动能力以对应说明为准；平台协议变更也可能影响连接。

### 画质名称为什么不是统一的 1080P？

插件显示直播间实际提供的档位。虎牙的蓝光码率名称不等于像素分辨率；其他平台也以返回的尺寸、帧率或档位名称为准。海外插件额外提供自动画质。

### 海外直播加载失败？

确认当前网络可访问相应平台。登录限制、年龄验证、会员内容或地区权限不在插件匿名公开直播的支持范围内。
