# 国内直播平台

虎牙、斗鱼与抖音集中展示，按自己的观看需求选择对应插件。每个平台独立安装、启用与更新。

## 下载选择

请先将本体升级到 0.8 热修复 1，再选择需要的平台。沿用原有关注、账号与分组，按包内声明接管对应平台并迁移设置，无需重新添加主播。

## 安装与迁移

优先在软件内的插件商店安装。手动下载后，在「设置 → 插件」导入对应 ZIP，启用后点击「重启以应用」。[查看安装与升级步骤](/guide#安装插件)。

原组合包中尚未被独立插件接管的平台可以继续使用。各平台的画质、聊天、登录及互动能力以对应发布说明为准。
